# Todo App

一款轻量级个人待办事项管理工具。支持清单分类、"我的一天"每日聚焦、子任务、提醒与截止日期、优先级与标签等核心功能。纯前端，数据存本地，无需登录，开箱即用。

## 功能

- 📋 清单管理：创建多个清单，分类管理任务
- ☀️ 我的一天：每日聚焦，智能推荐任务
- ✅ 任务管理：增删改查、标记完成/取消完成
- 📝 子任务：将复杂任务拆解为步骤
- ⏰ 提醒与截止日期：设置截止日期和提醒时间
- 🔁 重复任务：按天/周/月自动重复
- ⭐ 优先级与标签：星标重要任务，用 #标签 分类
- 📎 备注：记录额外信息
- 🔍 搜索与筛选：按关键词搜索，按状态筛选
- 📊 数据统计：总任务数、完成数、未完成数
- 💾 自动保存：数据存 localStorage，刷新不丢失
- 📱 响应式设计：手机电脑都适配

## 技术栈

HTML + CSS + JavaScript（原生） + localStorage

## 快速开始

1. 下载或克隆本仓库
2. 浏览器打开 `index.html`
3. 开始使用
