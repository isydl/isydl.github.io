# Todo App

## Overview

A lightweight personal todo list management tool. It supports list categorization, My Day view, subtasks, and deadline reminders. Built with pure frontend. No login required - just works out of the box with local data storage.

Here is the list of features:

- 📋 List management: create multiple lists to categorize and organize tasks.
- ☀️ My Day: daily focus with smart task suggestions.
- ✅ Task management: create, read, update, and delete tasks; mark as complete or incomplete.
- 📝 Subtasks: break down complex tasks into smaller steps.
- ⏰ Reminders & deadlines: set due dates and reminder times.
- 🔁 Recurring tasks: automatically repeat daily, weekly, or monthly.
- ⭐ Priority & tags: star important tasks and organize with #hashtags.
- 📎 Notes: add additional information to tasks.
- 🔍 Search & filter: search by keywords and filter by completion status.
- 📊 Statistics: view total, completed, and active task counts.
- 💾 Auto-save: data is stored in localStorage and persists after page refresh.
- 📱 Responsive design: adapts to both desktop and mobile screens.

Technology Stack:
HTML + CSS + JavaScript (Native) + localStorage

Quick Start:

1. Download or clone this repository
2. Open index.html in your browser
3. Start using it
