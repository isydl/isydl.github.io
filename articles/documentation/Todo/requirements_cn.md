# Todo 待办事项管理 - 需求文档

## 1. 产品概述

Todo 是一款个人待办事项管理工具，帮助用户高效地规划、追踪和管理日常任务。用户可以通过创建不同的任务清单来分类管理任务，并通过"我的一天"聚焦当日最重要的事项。

## 2. 用户角色

- 唯一用户：使用本设备的个人用户。

## 3. 功能需求

### 3.1 清单管理

**3.1.1 创建清单**

- 用户可以创建多个任务清单（如"工作"、"学习"、"生活"等），用于分类管理不同场景的任务。
- 系统默认提供一个名为"任务"的默认清单，不可删除。

**3.1.2 编辑与删除清单**

- 用户可以重命名清单名称。
- 用户可以删除清单，删除后清单内的所有任务一并移除（需二次确认）。

### 3.2 任务管理

**3.2.1 创建任务**

- 用户在清单内点击"添加任务"按钮，输入任务标题即可创建任务。
- 每个任务包含：ID（自增）、标题、所属清单、创建时间、截止日期（可选）、提醒时间（可选）、备注（可选）、优先级（可选）、完成状态。

**3.2.2 查看任务列表**

- 每个清单下展示该清单的所有任务。
- 任务按创建时间倒序排列（最新在上）。
- 已完成的任务显示为"已划掉"样式。

**3.2.3 编辑任务**

- 点击任务进入编辑页面，可修改标题、截止日期、提醒时间、备注、优先级等信息。

**3.2.4 删除任务**

- 每个任务支持删除操作，删除不可恢复。

**3.2.5 标记完成 / 取消完成**

- 点击任务前的复选框，切换任务的完成状态。
- 已完成任务可随时取消完成恢复原状。

### 3.3 "我的一天"（My Day）

**3.3.1 每日聚焦**

- "我的一天"是一个智能列表，帮助用户聚焦当日最重要的事项。
- 页面顶部显示当前日期。

**3.3.2 添加任务到"我的一天"**

- 用户可以从任意清单中选择任务添加到"我的一天"。
- 用户也可以在"我的一天"中直接创建新任务，该任务同时出现在默认清单中。

**3.3.3 建议功能**

- 点击建议图标，系统自动推荐：逾期未完成的任务、今日截止的任务、昨日未完成的任务。
- 用户可一键将推荐任务添加到"我的一天"。

**3.3.4 从"我的一天"移除任务**

- 完成任务后自动从"我的一天"移除。
- 用户也可手动将任务从"我的一天"移除（不影响原清单中的任务）。

### 3.4 子任务（步骤）

- 用户可以为任务添加子任务，将复杂任务拆解为更小的可执行单元。
- 子任务支持独立的完成/取消完成操作。

### 3.5 提醒与截止日期

- **截止日期**：用户可为任务设置截止日期。
- **提醒**：用户可为任务设置提醒时间。
- **重复任务**：用户可设置任务按天、周、月等周期重复。

### 3.6 备注

- 用户可为任务添加备注，记录额外信息。

### 3.7 优先级与标签

- **优先级**：用户可标记任务为"重要"（⭐星标），用于区分优先级。
- **标签**：用户可使用 `#标签` 为任务添加分类标签，便于检索和分组。

### 3.8 筛选与搜索

- 用户可按"全部 / 未完成 / 已完成"筛选任务列表。
- 用户可按关键词搜索任务标题。

### 3.9 数据统计

- 显示总任务数、已完成数、未完成数。
- 显示"我的一天"中当前待完成任务数量。

## 4. 非功能需求

| 项目       | 说明                                   |
| ---------- | -------------------------------------- |
| 数据持久化 | 使用 localStorage 存储，页面刷新不丢失 |
| 响应式布局 | 适配桌面与手机屏幕                     |
| 离线可用   | 无需网络连接                           |
| 零依赖     | 纯原生 HTML + CSS + JavaScript         |
