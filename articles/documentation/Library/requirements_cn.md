# 图书 / 电影收藏管理 - 需求文档

## 1. 产品概述

个人收藏管理工具，用于记录自己看过或想看的图书和电影，并对其进行分类、评分和备注。适合影迷和书虫整理自己的文化消费记录。

## 2. 用户角色

- 唯一用户：收藏者本人。

## 3. 功能需求

### 3.1 收藏列表展示

- 首页展示所有收藏条目，按添加时间倒序排列（最新添加排在最前面）。
- 每条显示：封面占位图（可用 emoji 或纯色方块代替）、标题、类型（图书/电影）、状态（想看/在看/已看）、评分（1-5 星）、添加时间。

### 3.2 添加收藏条目

- 点击"添加"按钮弹出表单。
- 表单字段：
  - 标题（必填）
  - 类型（图书 / 电影）
  - 状态（想看 / 在看 / 已看）
  - 评分（1-5 星，可选，默认为未评分）
  - 备注（可选）
- 提交后自动生成 ID 和时间戳。

### 3.3 编辑收藏条目

- 点击条目旁的"编辑"按钮，弹出已填充当前数据的表单。
- 可修改所有字段，保存后更新。

### 3.4 删除收藏条目

- 点击条目旁的"删除"按钮，确认后移除。
- 不可恢复。

### 3.5 搜索与筛选

- **搜索**：顶部搜索框，按标题关键词实时过滤。
- **筛选**：按下拉菜单分别按类型（全部 / 图书 / 电影）和状态（全部 / 想看 / 在看 / 已看）组合筛选。

### 3.6 数据统计

- 页面顶部或底部显示统计数据：
  - 总收藏数
  - 图书数量 / 电影数量
  - 已看数量 / 想看数量
  - 平均评分

## 4. 非功能需求

| 项目       | 说明                                   |
| ---------- | -------------------------------------- |
| 数据持久化 | 使用 localStorage 存储，页面刷新不丢失 |
| 响应式布局 | 适配桌面与手机屏幕                     |
| 评分交互   | 点击星标选择 1-5 星（悬停预览效果）    |
| 离线可用   | 无需网络连接                           |
| 零依赖     | 纯原生 HTML + CSS + JavaScript         |
