# 图书 / 电影收藏管理

一个个人收藏管理工具，帮你记录看过的、想看的图书和电影，还可以打分和写备注。

## 功能

- 📚 添加收藏：标题、类型、状态、评分、备注
- ✏️ 编辑收藏：随时修改条目信息
- 🗑️ 删除收藏：确认后移除
- ⭐ 评分系统：1-5 星，点击选择
- 🔍 搜索：按标题关键词搜索
- 🎯 筛选：按类型（图书/电影）和状态（想看/在看/已看）组合筛选
- 📊 数据统计：总数、分类数、已看数、平均分
- 💾 自动保存：刷新不丢失
- 📱 响应式设计：手机电脑都适配

## 技术栈

HTML + CSS + JavaScript（原生） + localStorage

## 快速开始

1. 下载仓库
2. 浏览器打开 `index.html`
3. 开始添加你的收藏
