# Pulse Technologies株式会社

企業向けクラウドサービスによる電子商取引基盤を開発・提供する企業。

主な事業内容：

- 企業向け電子商取引基盤の開発
- 注文管理機能の提供
- 在庫管理機能の提供
- 決済連携機能の提供
- 顧客管理機能の提供

---

## 会社による発見

会社は以下の事業状況を確認した。

- 日本市場における顧客数が継続的に増加している。

顧客から以下の要望が提出された。

> 大規模な販売促進活動に対応可能な企業向け電子商取引基盤を開発してほしい。

そのため、会社は以下の会議を開始した。
