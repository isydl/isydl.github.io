# 个人博客 / 笔记系统 - 需求文档

## 1. 产品概述

个人博客或笔记发布工具，用于撰写、编辑、保存和展示文章。纯前端，数据存本地，适合个人知识管理和写作练习。

## 2. 用户角色

- 唯一用户：作者本人。

## 3. 功能需求

### 3.1 文章列表展示

- 首页展示所有已保存文章，按更新时间倒序排列（最新修改的排在最前面）。
- 列表项显示：标题、摘要（自动从正文截取前 50 字）、发布时间、更新时间。

### 3.2 撰写新文章

- 点击"写文章"按钮进入编辑器页面。
- 编辑器包含：标题输入框、正文内容区（支持换行和基本排版）。
- 点击"保存"按钮保存文章，自动生成 ID 和时间戳。

### 3.3 编辑已有文章

- 在文章详情页或列表中点击"编辑"按钮，进入编辑器并填充已有内容。
- 保存后覆盖原文章，更新时间自动刷新。

### 3.4 删除文章

- 在文章详情页或列表中点击"删除"按钮，弹出确认框确认后移除文章。
- 删除操作不可恢复。

### 3.5 查看文章详情

- 点击列表中的文章标题，进入详情页，完整展示标题、正文、发布时间和更新时间。

### 3.6 文章状态

- 每篇文章可标记状态：草稿 / 已发布。
- 草稿文章在列表中显示特殊标记，不对外展示（自用场景下此功能仅用于视觉区分）。

### 3.7 搜索文章

- 顶部搜索框，按标题关键词实时过滤文章列表。

## 4. 非功能需求

| 项目       | 说明                                   |
| ---------- | -------------------------------------- |
| 数据持久化 | 使用 localStorage 存储，页面刷新不丢失 |
| 响应式布局 | 适配桌面与手机屏幕                     |
| 离线可用   | 无需网络连接                           |
| 零依赖     | 纯原生 HTML + CSS + JavaScript         |
