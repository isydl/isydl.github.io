# 个人博客 / 笔记系统

一个极简的个人文章发布与笔记工具。无数据库、无服务器，所有文章存在浏览器本地。

## 功能

- ✍️ 写文章：标题 + 正文，自动生成摘要
- 📝 编辑文章：随时修改已发布或草稿文章
- 🗑️ 删除文章：确认后移除
- 📄 文章列表：按更新时间倒序排列
- 🔍 搜索文章：按标题关键词搜索
- 📌 文章状态：草稿 / 已发布
- 💾 自动保存：刷新不丢失
- 📱 响应式设计：手机电脑都适配

## 技术栈

HTML + CSS + JavaScript（原生） + localStorage

## 快速开始

1. 下载仓库
2. 浏览器打开 `index.html`
3. 开始写你的第一篇博客
